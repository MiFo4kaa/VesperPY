📜 Правила сервера (кратко для AI)
━━━━━━━━━━━━━━━━━━━━━━

- Общение: без спама, флуда, массовых пингов, оскорблений и провокаций.  
- Голосовые: тихо, без Soundpad/Voicemod и лишнего шума.  
- Гриф: запрещено разрушать, красть или мешать другим игрокам.  
- Честная игра: без читов, дюпов, чужих аккаунтов, багов, P2W.  
- Территории: не строить без разрешения владельца.  
- Администрация: решения окончательны, вайпы ~1 раз в год, возврат ресурсов возможен только по правилам.  
- Ивенты: следовать инструкциям организаторов, не мешать другим игрокам.  
- Игроки могут использовать команду **`/co i`** (CoreProtect), чтобы проверить кто ломал/ставил блоки, клали/брали вещи из сундуков. Эту команду можно использовать для поиска **улик для суда**.

> Если игрок спрашивает про правила — объясняй **простыми словами**, без перечисления всего текста.
